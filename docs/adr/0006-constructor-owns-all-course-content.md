# The Constructor writes everything in a Course folder; the Tutor writes nothing there

Victor wants Courses to be shareable later, so a Course folder must be complete on its own and identical for whoever receives it. Therefore only Constructor Runs (build, add-rung, remediate) write into the folder, and Tutor conversations, Attempts, Verdicts, and marks live in the Progress DB. The tempting alternative, saving a good Tutor explanation back into the Lesson, was rejected because it makes every shared copy diverge and turns the Tutor into a silent editor of content the user believed was fixed.
