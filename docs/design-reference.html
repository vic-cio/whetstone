The chain rule

Module 02 / 8 min

When a function is built from other functions, its rate of change is the product of the rates at each layer. That is the whole idea, and every neural network trains on it.

Insight. Backpropagation is the chain rule applied in reverse order, once per layer, reusing what it already computed.
Try it

Differentiate f(x) = sin(3x²).

6x cos(3x²)
cos(3x²)
6x sin(3x²)
That's itOuter derivative cos(3x²), inner derivative 6x, multiplied.

Each layer contributes one factor. Multiply the factors and you have the gradient for the whole composition.

Tutor✕
Why is the inner derivative 6x?
Because the inside is 3x². Its derivative is 3 · 2x = 6x. The chain rule multiplies that by the outer derivative.
working.jpgIs my third line wrong?
Line three drops the inner derivative. You wrote cos(3x²) where it should be 6x · cos(3x²).
Ask, or drop in a photo…＋ ⌘V

A Lesson can still ask you things. A Try it question answers immediately and never becomes an Attempt. The Tutor takes files, images, and a pasted screenshot, so a photo of your working on paper is a normal thing to send it. The panel is closed until you open it, and opening it is what starts a conversation.

The toolkit

what every activity is built from

A Mini-app never writes its own buttons, colours, or message plumbing. The host injects one toolkit into every sandboxed frame, and the Constructor is told to build from it. That is what keeps a hand-cut joinery course and a machine learning course feeling like the same product, and it is the reason a Course can be interactive without each one inventing a look.

The toolkit is pinned per Course. A copy lives in the Course folder and the host injects that copy, so a Course behaves the same on another machine and a newer app never silently changes how a built Course works.

Kit.slider

learning rate 0.062

A parameter you drag, with a live readout. The workhorse for "see what this number does".

Kit.plot

Axes, curves, points, and a draggable marker. Redraws from the slider without the Mini-app touching a canvas.

Kit.pieces

∂L/∂wσ′(z)wᵀx

Drag tokens into ordered slots. Covers ordering, matching, labelling a diagram, and building an expression.

Kit.hotspot

Click or drag to mark a place on an image or a plot. The answer is a coordinate the host checks against a region.

Kit.editor

def backward(self, g):
  return g * self.cache
shapes matchnumeric checkbias gradient

A small code editor with the Constructor's assertions beside it. This is what an assertions-pass Task runs on.

Kit.steps

step 2 of 4 · forward pass
Next

A walkthrough the reader advances one beat at a time. Used for a derivation or an algorithm trace.

Kit.sim

A stepped model with a play control: a grid, a network, a signal. The Constructor supplies the rule, the toolkit supplies the loop and the transport.

Kit.bridge

Kit.ready()
Kit.answer(value)
Kit.review(png, state)
Kit.resize()

The only way out of the sandbox, and the whole protocol. A Mini-app reports; it never decides whether an answer was right.

Every widget inherits the tokens above, so an activity is in the same palette and type as the page around it and follows the theme without asking. A Mini-app that needs something the toolkit lacks may still write its own, and that is a signal the toolkit is missing a piece rather than a licence to restyle.

Rules of the direction

apply to every new screen
  1. Radius is zero everywhere, including buttons, inputs, ticks, and the sandbox frame.
  2. Separate with a rule, not a box. A hairline under a heading, a 1px frame at the window edge. Nothing floats and there are no drop shadows.
  3. Amber is a signal, not a colour. One primary action per screen, plus the selected item and a filled tick. Never a background wash.
  4. Metadata is monospace and small. Content is Inter Tight.
  5. The app counts, it never scores. Lessons done out of lessons total is the only progress figure anywhere. No streaks, no percentages, no ability estimate, no spend.
  6. The harness is never visible. No terminal, no tool names, no exit codes. Agent activity renders as short lines in the app's own vocabulary, and the raw stream stays behind a closed disclosure on the build screen only.
  7. The rail is the only dark surface, and a collapsed panel keeps that colour so the window keeps its shape.
  8. Motion is 150ms or nothing. Fades and panel collapse only.
  9. Activities are built from the toolkit, never hand-rolled. A widget that does not exist yet is a gap to fill in the toolkit, not a reason for one Course to look unlike the others.
  10. The interface does not explain itself. No heading that repeats the screen you are on, no label naming its own icons, no chip restating a rule you already learned.
